18 秒，三段各 6 秒；1920×1080、30fps、H.264 视频与 AAC 立体声。用于审阅动画语言，尚非正式 60–90 秒宣传片。

## 画面与动作

**火光照亮文明：**同一场景衍生出完整环境、人物与器物、近景边缘、独立火焰四层。透视相机拉开，远近图层产生不同速度的位移。火焰的局部形变和亮度变化驱动附近受光，烟雾按生命周期上升、扩散并淡出。

**文明成就成为玩家选择：**金字塔环境与建筑分层建立空间，随后镜头拉开并显露真实金字塔卡牌。宽幅插画在卡牌插画窗口中恢复为原卡插画；标题、文字、边框与数值采用原卡像素的独立覆盖层。卡牌倾转、减速落位；三种资源牌依次汇聚，投影跟随位置与高度变化。不演示规则支付或交易结果。

**飞向文明的下一章：**沿用已准备的深空、地球、飞船三层。相机跟随飞船，地球缓慢退远；推进光与短尾流以引擎位置为锚点，日出光以地球弧面为锚点。飞船和地球以小幅独立运动保持完整结构。

文字按分句显露，在场景建立后进入；可关闭文字独立检查画面。三段以短暗场分隔，作为三种动画能力的测试集合。

## 可编辑工程

- [统一参数](程序/参数.js)：时长、帧率、相机起终点、分层位置、落位时机、声音事件。坐标以 1920×1080 为基准。
- [动画与合成](程序/动画.js)：Three.js 透视场景、卡牌变换、局部受光、环境效果与文字。`init(canvas)` 完成加载；`render(seconds, {mode, text, effects})` 根据指定时间渲染，`mode` 为 `new` 或 `baseline`。超过范围的时间被限制在有效帧内。
- [预览控制](程序/预览.js)：播放按真实经过时间计算；拖动时间轴和逐帧始终定位到 30fps 的帧点。音频从相同时间位置播放。

Three.js **0.186.1** 已固定在 `程序/vendor/`，附 MIT 许可与来源。浏览器运行时无需访问外部 CDN。原有 `程序/画面.js` 只新增了可选的文字开关，默认行为保持原样。

同一时间、参数与种子在当前浏览器环境可重复呈现同一画面；不同设备的 GPU 浮点与抗锯齿结果可能略有差异。导出直接调用预览的渲染函数，以 `帧号 / 30` 驱动，不依赖实时播放速度或屏幕录制。

## 分层与声音来源

新增六份衍生素材均由内置 ImageGen 制作，完整提示词、参考原稿和生成来源保存在[生成记录](记录/生成记录.json)。实际尺寸、透明度、文件摘要与排版校准记录在[素材记录](记录/素材记录.json)。生成的人物透明层不是逐像素抠图，工程中已校准其比例和位置；原始美术与卡牌文件保持原样。

新增透明配图继续保存在原项目素材索引中；本样片的场景层直接参考对应宽幅原稿制作，避免因视角不同而强行拼接独立卡牌配图。

音乐使用已有原创电子管弦合成稿的 48–66 秒片段，并叠加火声、建造、纸质卡牌、电子脉冲与深空氛围。声音事件与落位采用同一秒制时间轴，输出额外保存[24bit 混音 WAV](输出/样片混音.wav)与[混音记录](记录/混音记录.json)。当前音乐是动作测试配乐，可替换用户制作的正式管弦配乐。

**分辨率限制仍然存在：**原场景及多数分层为 1672×941；火焰层为 1024×1536。1920×1080 是视频画布尺寸，不代表原插画已达到原生 1080p。当前允许有限镜头运动，高清补图留待动画方向确定之后。

## 重建与检查

运行 [本地预览服务](工具/本地预览.py)，默认地址 `http://127.0.0.1:18790/`。此服务支持视频分段读取，保证浏览器跳转播放位置正常。Python 使用 `宣传片/工具/.venv/bin/python`；新增依赖固定为 `imageio-ffmpeg==0.6.0`，其自带 FFmpeg **7.1**，不修改系统安装。其他依赖见[requirements](工具/requirements.txt)。

1. 运行 `工具/混音.py` 更新 18 秒混音。
2. 通过 Node 运行 `工具/导出视频.cjs`，逐帧输出新版与原版对照；可传入 `new` 仅更新新版。
3. 运行 `工具/合成对比.py` 生成左右对比视频。
4. 通过 Node 运行 `工具/检查帧.cjs`、`工具/检查交付.cjs`、`工具/检查播放.cjs`，再运行 `工具/检查视频.py` 记录浏览器功能、视频连续解码、帧数及尺寸。

本机导出使用独立临时 Chrome 配置，不读取个人浏览器会话。临时图像与解码缓存不纳入版本管理。
