# 《更迭》宣传片素材首版

横版、史诗感、文明共同创造与玩家参与；音乐、音效、屏幕文字，无旁白。制作依据为十个镜头的分镜草案，本批交付素材，不含最终视频剪辑。

**当前交付是可审阅、可继续制作动画的首版。生成插画原稿均为 1672×941，未达到计划的原生 1920×1080 最低尺寸，因此尚未通过全部验收。** 排版与组件合成图为 1920×1080；它们的输出尺寸不会被当作插画原稿的分辨率。

## 插画电影化动态样片

新增 [18 秒动态预览](动画/动态样片.html)、[带声音 MP4](动画/输出/更迭-插画电影化样片-v1.mp4) 与 [原版/新版对比](动画/输出/更迭-动画升级对比-v1.mp4)。包含火光分层与动态受光、场景收束成原卡、资源落位、飞船独立推进；制作说明与检查结果见 [动态样片说明](动画/README.md)。原生插画尺寸的限制仍然保留。

## 原图与生成记录

完整卡面、版图与透明原画保持原样。原有 130 份素材继续由 [原图索引](策划/素材索引.json) 管理；新增目录内的 141 份含 alpha PNG 已单独检查，其中 60 幅为独立透明配图，其余包括完整卡面、卡背和模板。

`星际航行.png` 对应成品卡的“宇宙航行”插画；图内地球、飞船和星空原本为一个整体。本批星辰三层从宽幅主图另行提取，没有把这个原文件误记为三个现成图层。

[生成记录](记录/生成记录.json) 保存完整提示词、参考路径、生成来源、版本、实际尺寸与摘要；三张早期探索稿保留在 `素材/主图/`，候选结果保留在 `素材/候选/`。新增画面不生成卡牌文字、数值或边框。

## 可编辑源与后续使用

文案源在 [准备资源工具](工具/准备资源.py) 的 `LINES` 中，版式在 [画面程序](程序/画面.js) 中。修改后重新构建清单并导出 PNG；SVG 可在支持文字编辑的矢量工具中继续排版。思源黑体 Regular/Bold 与许可位于 `素材/字体/`，在外部工具编辑 SVG 时需加载相应字体。

五类效果按固定进度和随机种子 `20261009` 驱动，相同参数得到相同画面。它们可叠加到剪辑工程；现有播放按钮用于检查运动，不代表最终镜头时长和剪辑节奏。

星辰图层按背景、地球、飞船依次叠放，全画布起点相同。[图层说明](素材/图层/BG-09/图层说明.json) 记录位置与运动余量。地球宜保持底边锚定并略微放大，防止上移后底边露空；当前镜头静帧使用完整主图。

配乐“文明向前”为 85 秒原创电子管弦合成版本，72 BPM、D 大调，另存弦乐空间、铜管主题、钟音脉动、鼓与金属四份分轨；属于可继续混音的合成配乐。电子脉冲和深空氛围也由可编辑程序生成。其余七类音效选取并处理公开录音，来源、作者、处理与摘要见 [声音记录](记录/声音记录.json)，原始下载文件及 CC0 来源页信息保存在 `素材/声音/来源/`。

## 维护与复现

- [索引透明配图](工具/索引透明配图.py)：重新检查新增原画，不修改原文件。
- [构建预览](工具/构建预览.py)：更新清单、可编辑 SVG 与旧入口。
- [导出预览](工具/导出预览.cjs)：通过本地浏览器导出文字、效果、构图、静帧和拼合检查。
- [制作声音](工具/制作声音.py)：重新合成配乐、分轨及原创音效，并下载处理录音；参数与种子固定。
- [检查素材](工具/检查素材.py)、[检查预览](工具/检查预览.cjs)：核对原图摘要、文件规格、透明度、音频信号和预览功能。

本地声音环境位于 `工具/.venv/`；依赖规格见 [requirements.txt](工具/requirements.txt)。浏览器导出工具使用本机 Chrome 与 Playwright；图片生成仍由内置 ImageGen 完成，生成记录用于后续复查和修改。
