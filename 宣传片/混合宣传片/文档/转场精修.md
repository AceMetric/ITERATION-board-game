## 实际采用的合成方法

`src/edit.json` 是画面和声音共同使用的逐处配置：时长、源素材窗口、相机区间、轮廓融合、印刷恢复、环境退场和声音提前/延续分别定义，不采用统一 0.8 秒规则。

`tools/prepare_bridges.py` 在项目现有 Python 虚拟环境中运行。主体轮廓和卡面对应点由人工测量，视频运动采用稀疏 LK 跟踪、双向稠密光流及人工锚点约束。火焰变化大，加入每六帧的轮廓约束以防追踪累积塌陷，并用亮度与暖色分离火焰；船体、建筑和纸页按对应轮廓控制点变形。此处不是自动语义分割，也不把像素检查当作视觉评价。

动态片段用三次 Hermite 源时间曲线，首尾回到原视频播放速度。相邻帧双向光流插值，原视频文件保持不变。每个输出帧的实际源时间与控制点存于 `src/tracking.json`。

主体离开原位置后，局部背景先使用相邻帧对齐样本重建；没有可见背景的区域再进行局部修补。修补仅作用于主体遮罩内，不再横移整幅视频制造第二个主体。完全被遮挡的大区域仍存在重建误差，故通过短暂的环境退场避免长时间暴露修补面。

三维相机用主体和卡面对应点校准画面中心与尺度，每处分别设置相机时间区间与贝塞尔节奏。主体轮廓采用分片仿射网格逐渐贴合卡面，取消统一弧线。主体和相机均按实际平移、缩放方向做 8 次曝光采样，模拟 180°快门；没有整幅画面的统一高斯模糊，停止运动后印刷内容恢复清晰。纸面连接改为较慢的 4 倍推进，工业连接为 3.5 倍推进，避免短时间极端放大造成跳动。近景卡面使用深度偏移，避免纸面与卡体在放大镜头中产生闪纹。

融合期间使用临时局部插画修补层，避免两个主体同时出现在卡上；印刷恢复后使用完整原图。原卡图、边框、名称、费用、卡背及版图文件不改写。FAST 只衔接上方星空，卡上的星空保持完整，不使用椭圆星光贴片，也不把反射面变为飞船。

声画共用逐处时间窗口，环境声采用分段保调缓速并各自提前进入/延续。片尾标题在融合完成后才出现；玩法说明在卡牌稳定后显现，AI 宣传语在主体转移开始时退场。

## 逐处安排

| 衔接 | 合成预算 | 实现 |
|---|---:|---|
| 片头 → 火光 | 1.0 秒 | 标题退去，金色光晕移向火堆，真实夜色和火光显现。 |
| 火光 → 驯火卡 | 1.6 秒 | 火焰暖色分离，环境短退，轮廓贴合卡面火焰，相机拉开。 |
| 学习科技 → 知识远航 | 1.0 秒 | 补牌落定后，相机靠近纺织卡的纸面和纤维，接入书册与港口。 |
| 知识远航 → 文字专利 | 1.4 秒 | 跟随前景纸页，贴合纸草卷方向与透视，拉开至专利镜头。 |
| 专利 → 金字塔 | 2.0 秒 | 从右下角待建奇观的插画靠近，建筑轮廓展开，随后显露沙漠与人物。 |
| 金字塔 → 奇观竞争 | 1.8 秒 | 顶点与建筑轮廓连续收束到插画，显露卡牌厚度与奇观位置。 |
| 奇观竞争 → 工业 | 1.2 秒 | 取回与弃置完成后靠近奇观材料，暖色空间展开；机械声提前进入。 |
| 工业 → FAST | 1.4 秒 | 有云雾起伏的斜向遮罩，承接蒸汽向上运动，机械声退去，山风进入。 |
| FAST → 最终挑战 | 1.6 秒 | 取原片上方星空的亮度与纹理，衔接卡面星空，再显露完整卡牌。 |
| 最终挑战 → 星辰未来 | 2.4 秒 | 先保留挑战结果和取得卡牌，相机靠近，船体沿船首方向展开，深空随后显现。 |
| 星辰未来 → 产品片尾 | 2.0 秒 | 船体与尾焰跟踪收束到产品卡，拉开产品构图，融合后才进入标题。 |

以上覆盖原剪辑点两侧，不增加全片时长。它们不是要求即梦重新生成的逐秒指令。

## 验证与边界

规则与几何核对、原文件摘要、所有跟踪帧的网格朝向/空遮罩/目标范围、24 个首尾端点、导出视频完整解码、相同转场帧重复渲染与转场全段相邻帧均有独立记录。解码检查同时保留原始像素变化、局部运动变化曲线及剪辑点相似变换对齐后的差异；不会把快速推拉造成的持续像素变化直接判为硬切，也不会单凭机器结果判定自然。它们分别证明对应技术性质，不能证明转场的艺术效果。

画面另按关键帧轨迹、正常播放和半速播放审看，记录见 `记录/转场视觉审看.md`。最终观感仍以实际视频为准。原 AI 视频为 852×480；统一输出 1080P 不等于 AI 原生 1080P。
